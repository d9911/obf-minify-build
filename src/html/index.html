🛡️ obf-minify-build Demo

✅ Активные защиты:

  • Запрет выделения текста
  • Блокировка контекстного меню
  • Защита от DevTools
  • Блокировка горячих клавиш (F12, Ctrl+Shift+I, etc.)
  • Защита от печати
⚠️ Внимание: Этот сайт защищен от инспекции. Попытка открыть DevTools может привести к блокировке контента.

🔧 Возможности obf-minify-build:

  • Автоматическая минификация HTML, CSS, JS
  • Обфускация JavaScript кода
  • Хеширование ассетов для кеширования
  • Встроенные защиты от копирования
  • CLI и API интерфейсы

📁 Структура проекта:

src/
├── html/          # HTML файлы
├── css/           # CSS стили
├── js/            # JavaScript файлы
├── assets/        # Изображения, шрифты
└── resources/     # Дополнительные ресурсы

🚀 Команды сборки:

  • npm run build — полная сборка
  • npm run dev — пересборка при изменениях
  • npm run start — сборка и запуск сервера
